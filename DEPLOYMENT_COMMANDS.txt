=================================================================
DEPLOYMENT COMMANDS - Copy and paste these in order
=================================================================

After you've completed Firebase setup and updated config.js,
use these commands to deploy:

-----------------------------------------------------------------
STEP 1: Initialize Git Repository
-----------------------------------------------------------------

cd gala-management
git init
git add .
git commit -m "Initial commit - YMU Gala 2026 Management System"


-----------------------------------------------------------------
STEP 2: Create GitHub Repository
-----------------------------------------------------------------

Go to: https://github.com/new

- Repository name: ymu-gala-2026
- Description: YMU Fundraising Gala Management System
- Choose: Private (recommended) or Public
- Do NOT initialize with README
- Click "Create repository"


-----------------------------------------------------------------
STEP 3: Push to GitHub
-----------------------------------------------------------------

IMPORTANT: Replace YOUR_USERNAME with your actual GitHub username!

git remote add origin https://github.com/YOUR_USERNAME/ymu-gala-2026.git
git branch -M main
git push -u origin main


-----------------------------------------------------------------
STEP 4: Enable GitHub Pages
-----------------------------------------------------------------

1. Go to: https://github.com/YOUR_USERNAME/ymu-gala-2026/settings/pages
2. Under "Source", select: "GitHub Actions"
3. Wait 2-3 minutes for deployment
4. Your app will be live at:
   https://YOUR_USERNAME.github.io/ymu-gala-2026/


-----------------------------------------------------------------
OPTIONAL: Future Updates
-----------------------------------------------------------------

After making changes to your code:

git add .
git commit -m "Description of changes"
git push

GitHub Pages will automatically redeploy!


-----------------------------------------------------------------
PYTHON COMMANDS (for data migration)
-----------------------------------------------------------------

Install dependencies:
pip install firebase-admin pandas openpyxl

Run migration:
cd scripts
python migrate_data.py

Use helper commands:
python db_helper.py list-vendors
python db_helper.py list-budget
python db_helper.py help
