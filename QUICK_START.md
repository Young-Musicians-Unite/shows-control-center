# Quick Start - YMU Gala 2026

**Get up and running in 30 minutes!**

## ✅ Checklist

- [ ] Firebase project created
- [ ] Firestore enabled
- [ ] Web app registered in Firebase
- [ ] `public/js/config.js` updated with your Firebase config
- [ ] Service account JSON downloaded and saved to `config/firebase-credentials.json`
- [ ] Python dependencies installed (`pip install firebase-admin pandas openpyxl`)
- [ ] Data migrated (`python scripts/migrate_data.py`)
- [ ] Local testing completed (open `public/index.html` in browser)
- [ ] GitHub repository created
- [ ] Code pushed to GitHub
- [ ] GitHub Pages enabled
- [ ] Live URL shared with team

## 🚀 3-Step Quick Start

### 1. Firebase Setup (10 min)
```
1. Create project at console.firebase.google.com
2. Enable Firestore Database
3. Copy web app config
4. Download service account key
5. Update public/js/config.js
6. Save key to config/firebase-credentials.json
```

### 2. Import Data (5 min)
```bash
pip install firebase-admin pandas openpyxl
cd scripts
python migrate_data.py
```

### 3. Deploy (5 min)
```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/ymu-gala-2026.git
git push -u origin main

# Then enable GitHub Pages in repo settings
```

## 📱 Your Live App

Once deployed, your app will be at:
```
https://YOUR_USERNAME.github.io/ymu-gala-2026/
```

Share this URL with your team (2-5 people)!
